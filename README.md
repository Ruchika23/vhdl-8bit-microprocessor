VHDL 8-Bit Microprocessor
Overview

This repository contains the design and implementation of an 8-bit microprocessor developed in VHDL.

The processor operates on a 50 MHz clock and executes instructions using a FETCH and EXECUTE cycle architecture. The design includes core processor components such as the Arithmetic Logic Unit (ALU), Program Counter, Control Unit, Address Registers, Loop Counter, Memory Interface, and display modules.

Features
8-bit microprocessor architecture
50 MHz clock operation
Fetch-Execute instruction cycle
Arithmetic and logical operations
Program counter and memory addressing
Loop counter implementation
Status register support
Simulation and verification using VHDL tools
